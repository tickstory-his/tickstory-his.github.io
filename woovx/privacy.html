woovx-uploader 개인정보처리방침

시행일: 2026년 11월 11일

1. 이 앱은 무엇인가요

woovx-uploader는 WOOVX 운영자가 직접 만든 영상을 WOOVX 유튜브 채널에 올리고, 그 영상의 조회 통계를 확인하기 위해 운영자 본인만 사용하는 도구입니다. 다른 사용자에게 제공하지 않습니다.

2. 어떤 정보에 접근하나요

운영자가 Google 계정으로 허용한 범위 안에서 다음 정보에만 접근합니다.

  • YouTube 채널 기본 정보(채널 이름, 구독자 수, 영상 수)
  • 영상 업로드와 영상 정보(제목, 설명, 공개 상태, 썸네일) 설정
  • YouTube Analytics의 채널·영상 통계(조회수, 시청 시간, 클릭률 등)

3. 정보를 어떻게 쓰고 보관하나요

  • 위 정보는 운영자 채널에 영상을 올리고 성과를 확인하는 데에만 씁니다.
  • 로그인 인증 정보(토큰)는 운영자의 개인 컴퓨터에만 저장되며, 별도 서버로 보내지 않습니다.
  • 어떤 정보도 판매하거나 제3자와 공유하지 않으며, 광고에 쓰지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

woovx-uploader가 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 앱은 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

5. 접근 권한 철회와 삭제

언제든지 Google 계정 → 보안 → 타사 앱 및 서비스에서 woovx-uploader의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없고, 운영자 컴퓨터의 토큰 파일도 삭제합니다.
